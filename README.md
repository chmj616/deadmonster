# 데드존 온라인 (Dead Monster)

몰려오는 좀비를 잡는 2.5D 좀비 서바이벌 웹 게임.

▶ 플레이: https://deadmonster.vercel.app

## 특징
- 세계지도 「잿빛 군도」 7개 섬 스토리 모드 (섬마다 10웨이브, 5웨이브 중간 보스 · 10웨이브 보스)
- 무기 7종 (돌격소총 · 펌프 샷건 · 용의 대검 · 화염방사기 · 수정 지팡이 · 저격소총 · 로켓런처), 무기별 Z·X·C·V 스킬
- X자형 스킬 트리 76노드 (스탯을 찍어 나가며 Z·X·C·V 해금)
- 탄창/장전, 상점 아이템(Q 수류탄 · E 구급상자 · F 아드레날린), 무한 모드

## 조작
WASD 이동 · Space/클릭 사격 · R 장전 · Q/E/F 아이템 · Z/X/C/V 무기 스킬 · 1~7 무기 · K 스킬 트리 · B 상점 · ESC 메뉴

단일 파일(index.html)로 동작하며 빌드가 필요 없습니다. 진행 상황은 브라우저 localStorage에 저장됩니다.
